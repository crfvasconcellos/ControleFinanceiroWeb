O que você consegue fazer

01

Registrar despesas e entradas

Cadastre transações com nome, valor, data, categoria e até comprovante em PDF. Cada registro é classificado automaticamente por prioridade (alta, média, baixa) conforme o valor.

02

Acompanhar pelo dashboard

Gráfico de evolução de gastos (mensal ou diário), resumo com saldo disponível, total gasto, número de transações e média mensal — tudo atualizado em tempo real.

03

Gerenciar recorrentes

Configure despesas e saldos fixos mensais (aluguel, salário, internet). O sistema gera automaticamente a cada mês, com opção de pausar e reativar.

04

Controlar orçamento

Defina um limite mensal e receba alertas visuais ao atingir 75%, 95% ou exceder o valor. A barra de progresso muda de cor conforme o consumo.

05

Filtrar, buscar e exportar

Filtre por mês, tipo, categoria ou valor. Busque transações por nome. Exporte tudo em CSV ou importe de arquivos externos.

06

Modo escuro e lixeira

Alterne entre tema claro e escuro. Transações excluídas vão para a lixeira e podem ser restauradas a qualquer momento.

Tecnologias e arquitetura

Stack

  • PHP 8.x — Backend com padrão MVC
  • MySQL / MariaDB — Banco de dados relacional
  • PDO — Queries parametrizadas (segurança)
  • HTML5 + CSS3 — Interface responsiva, zero frameworks JS
  • SVG — Gráficos dinâmicos gerados pelo servidor
  • PHPUnit 9 — Testes automatizados com banco real

Como rodar localmente

1
Pré-requisitos

PHP 8.0+, MySQL ou MariaDB, extensão pdo_mysql

2
Clone e crie o banco 
git clone https://github.com/crfvasconcellos/ControleFinanceiroWeb.git
mysql -u root -p -e "CREATE DATABASE controle_financeiro CHARACTER SET utf8mb4;"
3
Inicie o servidor 
cd Projeto/public && php -S localhost:8000
4
Acesse 
http://localhost:8000
